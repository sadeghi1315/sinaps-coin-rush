SINAPS COIN RUSH 3D — نسخه نمایشی مستقل

انتشار در GitHub Pages:
1) فایل ZIP را استخراج کنید.
2) فایل index.html را در ریشه مخزن sinaps-coin-rush جایگزین کنید.
3) در GitHub Pages مطمئن شوید Source روی Deploy from a branch، Branch روی main و Folder روی /(root) است.
4) بعد از انتشار، صفحه بازی را با رفرش اجباری باز کنید یا در مرورگر یک تب ناشناس باز کنید.

کنترل موبایل: سوایپ چپ/راست برای تغییر مسیر، سوایپ بالا برای پرش.
این بازی مستقل و نمایشی است؛ سکه‌ها SNP واقعی نیستند و به سرور SINAPS وصل نیستند.
